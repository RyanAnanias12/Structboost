## 📋 Sobre o Projeto

O **Structboost** é uma landing page desenvolvida para promover um curso completo de Front-end. O projeto apresenta seções bem definidas para atrair e converter visitantes, com foco em design limpo, animações suaves e performance otimizada.

## ✨ Funcionalidades

- **Hero Section** — Apresentação impactante com chamada para ação (CTA)
- **Seção de Diferenciais** — Cards destacando impacto visual, navegabilidade e performance
- **Grade de Módulos** — Cards dos conteúdos do curso (HTML5, CSS3, JavaScript, Frameworks, Design Responsivo)
- **Newsletter / CTA Final** — Chamada para lista de espera
- **Footer Completo** — Navegação, soluções, contato e redes sociais
- **Menu Mobile** — Navbar responsiva com botão hamburger
- **Animações AOS** — Efeitos de entrada suaves ao rolar a página

## 🚀 Como Executar

Este projeto não possui dependências de build — basta abrir o arquivo HTML no navegador.

```bash
# Clone o repositório
git clone https://github.com/RyanAnanias12/Structboost.git

# Acesse a pasta
cd Structboost

# Abra no navegador
open index.html
```

Ou simplesmente acesse a versão hospedada: **[structboost-six.vercel.app](https://structboost-six.vercel.app)**
