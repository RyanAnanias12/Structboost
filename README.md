# Structboost 🚀

## 📋 Sobre o Projeto

O **Structboost** é uma landing page que promove um curso completo de Front-end, oferecendo:

- **Design Moderno**: Interface limpa e profissional
- **Responsividade**: Adaptação perfeita para todos os dispositivos
- **Animações**: Efeitos visuais suaves com AOS (Animate On Scroll)
- **Performance**: Código otimizado e carregamento rápido
- **Acessibilidade**: Estrutura semântica e navegação intuitiva
